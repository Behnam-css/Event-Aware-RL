# E-EARL Event-Priority Experiment Report

## Scientific question

Does adding inferred event-boundary and time-since-boundary features to the same classical average-reward RL algorithm improve both reward rate and survival over a current-schema-only agent?

## Design

- Independent training seeds: **30**.
- Episodes per method and seed: **1800**.
- Horizon: **420** time steps; held-out episodes per method/seed/scenario: **60**.
- Shared learner: tabular differential Q-learning; no neural networks.
- Primary contrast: event-aware minus schema-only on the matched timed-refuge ecology.
- Co-primary endpoints: reward per elapsed step and survival probability.
- Primary familywise error: Holm correction over both endpoints.
- Negative control: boundaries generated by an independent shuffled event stream.
- Upper bound: oracle event schema/boundary timing; not an ordinary fair baseline.

## Ecological manipulation

The environment cycles through forage, warning, attack, and recovery events. Reward draws and predator draws use separate random streams. During a warning event, remaining outside permits foraging, but entering the refuge too early makes it vulnerable to a predator raid at the subsequent attack transition; waiting outside until attack onset exposes the animal to an ambush. The timing constraint is explicit and shared by all conditions. This is a diagnostic benchmark designed to test temporally structured state representations, not a claim that all ecologies have a refuge-tenure effect.

## Interpretation safeguards

The event-aware representation is supported on this benchmark only if both co-primary endpoints favor event-aware and their Holm-adjusted p-values are below .05. The shuffled-boundary condition checks whether any extra temporal feature is sufficient; the flat-refuge condition removes the refuge-tenure component but retains predictable warning-to-attack timing. A residual gain there is compatible with event-age information improving the timing of shelter entry; it is not a null condition in which event age is guaranteed irrelevant. The oracle agent is a privileged upper bound and should not be described as a fair deployable competitor.

The experiment uses a fixed cue-change detector (argmax of a noisy four-channel cue), not a learned boundary detector. Exploratory development pilots first showed reward-rate gains without a clear survival gain; the task was then revised to make attack/raid severity and the shared injury cost explicit, and the final 30-seed run used fresh seed IDs (1000–1029). Thus the final sample is independent of those development seeds, but the task design itself was refined after exploratory observations. The current p-values support the frozen synthetic benchmark; they should not be treated as evidence that the entire task-design hypothesis was independently preregistered. Before a strong ICML-wide claim, preregister parameter ranges and replicate in a second ecology. The study tests the utility of event-structured state features, not learned event discovery, neural plausibility, or universal superiority.

In the high-noise and wider-warning test regimes, the reward-rate contrast remains positive but the survival contrast is not reliably positive. Report this as a limitation: the primary survival result is established for the matched diagnostic ecology, not for every distribution shift.

## Reproducibility

The raw training/evaluation episodes, configuration, seed-level aggregates, paired inference, policy tables and figures are included in the result archive. Evaluation episodes are nested within a trained seed; the independent unit for inference is the training seed, not the individual episode.

## Separate paper-inspired patch-foraging calibration

Zeraati et al. describe a three-patch task where reward probabilities deplete with exploitation and replenish over time, with an average-reward MDP solved using policy iteration and comparisons to MVT/single-threshold policies. The supplied calibration follows that broad model class, but it is not an exact reproduction. Its reward rates are not directly comparable to the foraging-defense ecology because its state/action/reward structure differs. See the paper abstract: https://2025.ccneuro.org/abstract_pdf/Zeraati_2025_Optimal_Foraging_Learning_World_Model.pdf.
