# Analysis plan — E-EARL Event-Priority benchmark

## Frozen primary hypothesis

In the matched timed-refuge ecology, a tabular differential Q-learning agent with a cue-inferred event-age state should outperform a current-schema-only agent on both reward rate and episode survival.

## Primary estimand and outcomes

The unit of inference is an independently trained policy seed. For each seed and agent, the 60 held-out episode metrics are averaged within seed before inference. The main paired effect is:

`delta_seed = mean_metric(event_aware, matched, seed) - mean_metric(schema_only, matched, seed)`.

Co-primary outcomes:

1. `reward_rate`: total reward divided by elapsed decision steps before episode termination or horizon.
2. `survival`: indicator that the agent reached the full episode horizon without death, averaged over held-out episodes.

The confirmatory comparison uses 30 independent training seeds (seed IDs 1000–1029), 1,800 training episodes per agent and seed, 420-step maximum horizon, and 60 matched held-out episodes per agent/seed/scenario.

## Inference

- Paired two-sided one-sample t-tests of seed-level differences against zero.
- Holm family-wise correction across the two co-primary p-values.
- Percentile bootstrap 95% confidence intervals from 20,000 resamples of independent seed-level differences. These intervals are not multiplicity-adjusted.
- Wilcoxon signed-rank p-values and fraction of positive seed-level differences are also reported as sensitivity summaries.
- Secondary contrasts and stress scenarios are exploratory. Their unadjusted p-values must not be presented as confirmatory.
- The oracle-event condition receives true event labels and is an upper-bound diagnostic, not a fair deployable baseline.

## Comparators

All primary learned conditions use the same action space, tabular differential Q-learning update, exploration schedule and task/reward mechanics:

- `no_event`: ecological state features only;
- `schema_only`: the same ecological state plus current sensory-cue-decoded schema;
- `event_aware`: the same as schema-only plus event age reset when the decoded schema changes;
- `shuffled_event`: same as schema-only plus age generated by an independent event stream;
- `oracle_event`: true schema and true event age, for diagnostic upper bound only.

The primary EA-vs-schema-only contrast isolates temporal event information from current schema information. EA-vs-no-event alone would confound those components.

## Robustness regimes

- `noisy_cues`: raises cue noise from 0.12 to 0.23; detector quality is measured against the hidden event stream after the run.
- `flat_refuge`: removes the refuge-occupancy raid hazard, but preserves warning-to-attack predictability. It is a mechanism control, not a null in which event age is guaranteed irrelevant.
- `wide_warning`: broadens the warning-duration distribution and tests timing generalization.

## Scientific caution

The task was refined after exploratory pilots because the first version showed reward-rate benefits without clear survival benefits. The final confirmatory sample uses fresh seed IDs, but the task design itself was informed by those exploratory observations. Report p-values as conditional on this frozen synthetic benchmark. A second independently designed ecology and a pre-registered sensitivity analysis are needed for a broader claim.
