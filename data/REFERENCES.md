# Reference used for the auxiliary patch-foraging calibration

Zeraati, R., Oña Jodar, T., Safavi, S., Cruz, B., Poo, C., & Dayan, P. (2025). *Optimal Foraging by Learning the World Model*. Computational and Cognitive Neuroscience (CCN) 2025 abstract.

Publisher PDF: https://2025.ccneuro.org/abstract_pdf/Zeraati_2025_Optimal_Foraging_Learning_World_Model.pdf

The abstract describes an average-reward RL framework that formulates a three-patch depletion/replenishment task as an MDP and uses average-reward policy iteration to obtain an optimal policy, comparing behavior/reward rates with Marginal Value Theorem and single-threshold policies. The bundled calibration reproduces that broad model class with a discretized MDP; it is not an exact numerical or code replication. Its reward rates must not be pooled with or directly compared to the main foraging-defense experiment.
