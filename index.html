When the world changes, timing becomes state.

E-EARL asks a simple but consequential question: can a classical reinforcement-learning agent make better decisions when it represents not only what situation it is in, but also how far that situation has unfolded?

We test event-relative time in a synthetic foraging-and-defense ecology, keeping the learning algorithm fixed and changing the representation available to the agent.

01 / The theoretical argument

From a stream of states to a sequence of situations.

Ordinary RL learns how actions pay off in states. But in a changing ecology, the same visible situation can demand different actions depending on whether a transition is near, has just occurred, or is receding. Event perception offers a principled way to represent that temporal structure.

The cognitive premise

Boundaries are more than labels.

In event-segmentation accounts, perception is organized into meaningful episodes. A transient mismatch between predicted and observed dynamics can prompt an event-model update; boundaries help organize what is happening now and what is likely to happen next. Zacks and colleagues developed a mind–brain framework in which event models are updated following prediction-error signals, and subsequent work describes event segmentation as hierarchically organized rather than a flat list of snapshots.

This project borrows the computational motivation, not a claim that the implemented detector replicates the cognitive mechanism.

The RL problem

A stationary policy can be blind to temporal position.

If a policy sees only the category warning, it must choose the same action whenever the other represented variables are identical. Yet early warning and late warning can differ in both opportunity and danger. Adding an event-age variable turns hidden temporal position into an explicit feature that a stationary value function can condition on.

The key question is representational: does event-relative time improve control when the environment makes it useful?

Central hypothesis. When action consequences depend on temporal position within an ecological event, augmenting a classical RL state with an inferred event boundary and elapsed time should improve reward rate and survival over a matched agent that knows the current schema but not event age.

Why compare against schema-only?

A no-event comparison alone is not diagnostic: it changes two things at once—the identity of the current situation and information about its temporal progression. Schema-only receives the same cue-decoded current schema as event-aware. The primary contrast therefore asks whether event-relative time adds value beyond schema identity.

What “priority” means here

It is a claim about the functional role of event inference in organizing action, not a claim that event perception replaces world models, cognitive maps, or RL. The benchmark operationalizes event awareness as a boundary-reset clock; stronger future work should test learned segmentation and distinct ecologies.

02 / The ecology

A foraging animal cannot just ask, “What is happening?”

It must also ask: “How far into this episode am I, and how soon will the situation change?” The synthetic environment makes that difference consequential by coupling food opportunities to a warning–attack cycle and a temporary refuge.

The phases repeat, with durations sampled from a prespecified range. All agents share the same ecology, action costs, reward outcomes and event schedule within paired comparisons.

Opportunity

Two resource patches

Food is probabilistic and depletes after successful harvest, while inactive resources replenish toward their maxima. Patch switching trades travel cost against future return.

Threat

Attack onset and exposure

During warning, an agent can forage while outside. An attack can injure exposed agents; a refuge occupied for at least 11 steps can also become raid-prone at the transition.

Control

Four actions

Forage, switch patch, seek shelter, or rest/defend. The optimal timing balances immediate food, action costs, injury risk and survival.

Illustrative within-event control logic
Earlier: exploit resourcesBoundary approachesLate warning: shelterAttack: survive / recover

This timeline communicates the policy logic implied by the task. It is a schematic, not an observed action trace.

Scientific design choice—and its boundary

The refuge-tenure rule is deliberately explicit to create a falsifiable test of event-relative time. It makes elapsed time useful by construction. That is appropriate for a mechanism-focused diagnostic benchmark, but it also narrows the claim: the finding does not show that event age is universally valuable, or that all animal ecologies contain this exact refuge constraint.

03 / Representation & learning

Event inference and state augmentation

The event-aware detector is deliberately transparent and fixed: the four-dimensional noisy sensory cue is decoded using argmax. If the decoded schema changes, the event clock resets. At time t, event age is τₜ = t − t_boundary. It is then discretized into six bins: 0–1, 2–4, 5–7, 8–10, 11–13, and 14+ steps. This design tests the control value of an event-relative state feature; it does not learn event segmentation from raw observations.

Average-reward differential Q-learning

The foraging-defense task is continuing and cyclical: the objective is not merely to maximize a finite discounted sum but to sustain reward through time. We use a tabular average-reward TD update. For a transition from state s under action a, reward r, and next state s′, the implementation computes:

δₜ = rₜ − ρ̂ₜ + maxₐ′ Q(sₜ₊₁, a′) − Q(sₜ, aₜ)
Q(sₜ, aₜ) ← Q(sₜ, aₜ) + α δₜ
ρ̂ₜ ← ρ̂ₜ + β δₜ   (when the selected action was greedy)

Here, ρ̂ estimates average gain, α = 0.13 is the action-value step size and β = 0.004 is the gain-estimate step size. Policies use ε-greedy action selection: ε decays linearly from 1.0 to 0.04 across the first 75% of training. Hyperparameters and action definitions are shared across the primary learned conditions.

Algorithm 1 · high-level pseudocoderepresentation intervention
initialize tabular Q(s, a) and average-gain estimate rho
for each training episode:
    sample a paired ecology / cue / reward / threat stream
    for each decision t:
        decode current schema c_t from sensory cue
        if c_t differs from c_(t-1): reset event clock
        compute event age tau_t and discretize phi(tau_t)
        construct s_t according to experimental condition
        choose a_t with epsilon-greedy Q(s_t, ·)
        execute a_t; observe reward r_t and next state s_(t+1)
        delta = r_t - rho + max_a Q(s_(t+1), a) - Q(s_t, a_t)
        Q(s_t, a_t) += alpha * delta
        if a_t was greedy: rho += beta * delta

primary test: event-aware vs schema-only, at matched test conditions

Interpretation of the algorithmic contribution. This experiment does not propose a new value-learning rule. Its intervention is in the state representation: inferred temporal structure is made available to an otherwise matched classical RL controller. The central scientific question is whether this representational change is useful, not whether one model family is more powerful than another.

04 / Experimental protocol and results

A matched-seed test of reward and survival.

The primary test compares event-aware against schema-only in the matched timed-refuge ecology. Each independently trained policy is evaluated on 60 held-out episodes per scenario; episode scores are averaged within training seed before inference. The seed—not each individual evaluation episode—is the unit of statistical replication.

Confirmatory profile

Experimental budget

  • 30 independent training seeds (IDs 1000–1029)
  • 1,800 training episodes per condition and seed
  • 420 decisions maximum per episode
  • 60 held-out episodes per condition, seed, scenario
  • 5 agent conditions × 4 test scenarios
  • 270,000 training episode rows
  • 36,000 evaluation episode rows
  • 150 saved tabular-policy checkpoints

Pre-specified primary contrast

For every training seed, the held-out metrics were averaged over evaluation episodes. We calculated paired seed-level differences, bootstrap 95% confidence intervals from 20,000 resamples, and paired two-sided t-tests. Holm correction was applied across the two co-primary endpoints: reward rate and survival.

Secondary comparisons, diagnostic controls, and stress-scenario contrasts are descriptive or exploratory; their unadjusted values should not be presented as confirmatory hypothesis tests.

What the primary test says

Event-relative time carries control value here.

The event-aware condition exceeded schema-only by 0.2032 reward units per decision, with a seed-bootstrap 95% CI of [0.1847, 0.2209]. The difference was positive in all 30 training seeds. Survival improved by 17.1 percentage points, positive in 29 of 30 seeds. Both co-primary tests remained significant after Holm correction.

What still needs testing

The effect is ecology-dependent.

The oracle-event condition is privileged and is not a fair deployable model. Under wider warning durations and noisier cues, event-relative timing still helps reward rate, but the survival benefit is not reliable. A second independently designed ecology is needed before claiming broad generality.

05 / Robustness and interpretation

A result worth explaining, not just celebrating.

The main result is statistically clear within the matched diagnostic ecology. The robustness tests show where the proposed mechanism starts to lose its leverage.

Important caveats for a paper

  • Task-design iteration: exploratory pilots first showed reward gains without a clear survival gain. Task mechanics were subsequently revised to make injury/death consequences and refuge raids explicit. Final seed IDs (1000–1029) are fresh relative to the pilots, but the task design was informed by their outcomes. This is disclosed in the development history; it should not be described as a fully blind preregistered design.
  • Fixed event detector: boundaries are cue-category changes, not inferred from learned predictions or raw perceptual prediction error. The current experiment tests the utility of event-structured features, not autonomous event discovery.
  • Synthetic environment: this is a discrete, hand-designed foraging-and-defense simulator, not MuJoCo physics and not a validated animal model.
  • One task family: the refuge-tenure constraint makes event age consequential by design. Broad generality requires a second independently designed task, prespecified parameter sweeps, and stronger tests under distribution shift.
  • Representation capacity: adding event age expands the tabular state space. The shuffled event control helps test whether arbitrary timing is enough, but future work should more fully match representational capacity and learning difficulty.
06 / Code and computational framework

Small, transparent, reproducible by design.

The implementation emphasizes auditability over architectural complexity. A compiled CPU kernel runs episodes; state representations are explicit; raw episode-level metrics, seed-level aggregates, statistical outputs and figures are written to disk.

Framework stack

Python ≥ 3.10NumPyPandasSciPyMatplotlibNumba CPU JITpytest

No GPU or neural-network framework is required. Numba compiles the step-level environment/update kernel to make the 270,000-episode training workload practical on CPU. NumPy stores tabular Q values and sampled random streams; Pandas handles the long-form result tables; SciPy and a seed bootstrap support inference; Matplotlib writes the plotted figures.
